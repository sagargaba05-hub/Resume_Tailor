How this works & setup notes
Your JD (plus any resume you upload) is sent to a GitHub Action in this repo via repository_dispatch. The Action tailors the CV — keyword injection, bullet reorder, ATS-safe HTML — using Anthropic's API, runs generate-pdf.mjs, and commits the PDF to tailored/. This page polls for completion and gives you the download link.

Required setup:
  • Add ANTHROPIC_API_KEY as a repository secret (Settings → Secrets and variables → Actions).
  • Enable GitHub Pages on main /docs.
  • Your GitHub PAT stays in your browser only.
